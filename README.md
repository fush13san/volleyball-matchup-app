# volleyball-matchup-app

バレーボールの試合中に、両チームのマッチアップ（対面する選手）を一瞬で確認できるシンプルなWebアプリです。

## 使い方

1. `index.html` をブラウザで開きます（ビルド不要・インストール不要）。
2. 両チームのスタメンの背番号を、サーブ順（ポジション1〜6）に入力します。
3. 最初のサーブ権を選び、「試合開始」をタップします。
4. 得点が入ったチームの「〇〇 得点」ボタンをタップすると、サイドアウト（サーブ権交代）時のみ自動的にそのチームがローテーションし、常に最新のマッチアップ（特に前衛のブロック対決）が一目でわかります。
5. 入力ミスは「1つ戻す」で取り消し、選手交代など特殊なケースは「手動回転」ボタンで個別に調整できます。
6. 「スタメン編集」でスタメン入力からやり直せます。

入力内容と試合状況はブラウザのローカルストレージに保存されるため、誤ってページを再読み込みしても復元されます。

## 技術構成

- 依存ライブラリなしの単一HTMLファイル（`index.html`）。サーバーやビルドツールは不要です。
